ChatGPT Models 1.0.0 by liboy

- Manage multiple OpenAI-compatible API endpoints in native Flow Launcher settings.
- Fetch each endpoint's model list and choose or manually enter a model.
- Cache model lists independently and preserve selections on refresh failure.
- Use custom system prompts, copy answers, and open answers in a text editor.

Independent community plugin based on MichielvanBeers/Flow.Launcher.Plugin.ChatGPT (MIT).
